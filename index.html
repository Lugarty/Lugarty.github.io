03

Projeto em destaque

Projeto autoral · Em desenvolvimento

Insigni Ordis IO

O IO é um servidor MCP (Model Context Protocol) que conecta agentes de IA ao computador do usuário. A partir de um cliente compatível, o agente pode interagir com aplicativos, arquivos, mouse, teclado e navegador no Windows.

O projeto explora a automação de fluxos que atravessam diferentes ferramentas, inclusive quando não existem APIs específicas. Permissões e mecanismos de supervisão humana ajudam a manter a execução sob controle.

O código-fonte não está público. Esta apresentação descreve apenas o conceito e as capacidades gerais do projeto.
