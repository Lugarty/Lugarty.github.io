# Personal website
## Website

- [Brazilian Portuguese](https://lugarty.github.io/)
- [English](https://lugarty.github.io/en/)

## Structure

- `index.html`: Brazilian Portuguese version.
- `en/index.html`: English version.
- `assets/style.css`: Shared responsive stylesheet.
- `assets/icon.svg`: Site icon.
- `assets/site.js`: Progressive enhancement, scroll effects and a bilingual interactive workflow demonstration.
- `.nojekyll`: Disables Jekyll processing.

The site uses static HTML, CSS and vanilla JavaScript, with no build step or external runtime dependencies. The interactive demonstration visualizes fictional browser, file and desktop workflows, with human review and outcome verification. It is a local simulation and does not execute real computer actions. The core portfolio remains readable without JavaScript. Serve the repository root with a local HTTP server to preview it.

## Deployment

GitHub Pages serves the `main` branch from the repository root.
