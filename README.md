# Personal Portfolio

Personal website of Anísio Oliveira, a Software Engineering student focused on backend development, automation and applied AI.

## Website

- [Brazilian Portuguese](https://lugarty.github.io/)
- [English](https://lugarty.github.io/en/)

## Structure

- `index.html`: Brazilian Portuguese version.
- `en/index.html`: English version.
- `assets/style.css`: Shared responsive stylesheet.
- `assets/icon.svg`: Site icon.
- `.nojekyll`: Disables Jekyll processing.

The site uses static HTML and CSS, with no build step or external runtime dependencies. Serve the repository root with a local HTTP server to preview it.

## Deployment

GitHub Pages serves the `main` branch from the repository root.
