Featured project

Independent project · In development

Insigni Ordis IO

IO is an MCP (Model Context Protocol) server that connects AI agents to the user's computer. Through a compatible client, an agent can interact with Windows applications, files, mouse, keyboard and browser.

The project explores automation across different tools, including those without dedicated APIs. Permissions and human oversight mechanisms help keep execution under control.

The source code is not public. This overview describes only the project's concept and general capabilities.
